# Lorcana-Tracker

**Match-Log** – Web-App zum Eintragen und Auswerten von Disney-Lorcana-Matches
(Bo1/Bo3, Gegnerfarben und -varianten, Lore-Zähler, Statistiken, Verlauf, Replay-Import von duels.ink).

## Benutzen

`index.html` im Browser öffnen – fertig. Kein Build, kein Server nötig.

- Daten werden lokal im Browser gespeichert (localStorage), also pro Gerät und Browser.
- Sicherung: im Tab „Verlauf“ exportieren/importieren bzw. CSV herunterladen.

Ursprünglich als Claude-Artefakt erstellt: https://claude.ai/artifact/MGgCBwgvejwudebZjkwufP
